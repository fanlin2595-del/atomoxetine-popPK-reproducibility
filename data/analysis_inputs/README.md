# Local analysis inputs (not for public upload)

This folder is an optional local staging area for source outputs needed by the analysis scripts. It is ignored by Git so that empirical, potentially patient-derived files are not accidentally committed. Keep all source data covered by the applicable institutional and ethics restrictions.

Expected subfolders and files are listed in [`../../docs/FILE_INVENTORY.md`](../../docs/FILE_INVENTORY.md). Alternatively, point a script to a local authorized input directory using its documented `ATX_*_INPUT_DIR` environment variable. Relative override paths are interpreted from the project root.
